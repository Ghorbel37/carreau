# Carreau

A 2D mobile puzzle game based on a notebook sketch: four pieces sit in the corners of a square board, and swipes reshape them.

## Rules

Each corner piece is one of four shapes:

| Shape | Width × height |
| --- | --- |
| Carreau (small square) | 1 × 1 |
| Rectangle horizontal | 2 × 1 |
| Rectangle vertical | 1 × 2 |
| Carreau grand (big square) | 2 × 2 |

- A **horizontal swipe** (← or →) toggles a piece's width: carreau ↔ rectangle horizontal, rectangle vertical ↔ carreau grand.
- A **vertical swipe** (↑ or ↓) toggles its height: carreau ↔ rectangle vertical, rectangle horizontal ↔ carreau grand.
- Where you swipe picks the pair: a horizontal swipe in the top half affects the two top pieces, bottom half the two bottom ones; a vertical swipe in the left half affects the two left pieces, right half the two right ones. The arrows around the board do the same when tapped.

Desktop: arrow keys or W A S D (the arrow points at the edge it works). Esc quits a game.

## Modes

- **Rush**: match as many target shapes as you can in 60 seconds. A match in the fewest possible moves gives +3 s, any other match +1 s.
- **Levels**: 30 fixed puzzles with a move limit. From level 9, two or three targets must be hit in order. Fewest moves earns ★★★, one detour (two extra moves) ★★, otherwise ★. Levels 25–30 must be solved perfectly. Clearing a level unlocks the next.
- **Memory**: the target shows briefly, then hides. Rebuild it in exactly the minimum number of moves. Three lives.
- **Zen**: endless targets, no clock.

Sound (synthesized with Web Audio) and vibration on a correct match can each be switched off with the buttons in the top right. Settings, best scores and level stars are saved on the device.

Every swipe flips exactly one edge, so the number of moves you make always has the same parity as the minimum. That is why star thresholds and level move limits step by two.

## Project layout

| Path | What it is |
| --- | --- |
| `www/` | The game: `index.html`, `core.js` (rules, shared with the tests), self-hosted fonts, icons, web manifest and offline service worker |
| `android/` | Capacitor Android project (generated by `npx cap add android`, icons from `assets/`) |
| `assets/` | Source images for the Android icon and splash (`npx @capacitor/assets generate --android`) |
| `test/unit/` | Rule tests (`node --test`) |
| `test/e2e/` | Playwright tests that play every mode on a phone and a desktop viewport |

## Develop

```sh
npm install
npm start            # http://localhost:4173
npm test             # unit + browser tests (run `npx playwright install chromium` once)
```

## Android

The web game is wrapped with [Capacitor](https://capacitorjs.com/). Vibration in the app uses the native Haptics plugin.

```sh
npm run android:build   # needs JDK 21 and the Android SDK
```

The APK lands in `android/app/build/outputs/apk/debug/`. CI builds it on every push: open the run in the Actions tab and download the `carreau-debug-apk` artifact, then install it on your phone (allow installs from unknown sources).

## CI

`.github/workflows/ci.yml` runs the unit tests and the browser tests, then builds the debug APK.
